## Company overview

VS Softech is a fictional software and IT services company used in this demo. It helps businesses explore web applications, mobile applications, workflow automation and software integrations.

The sample company's business assistant helps prospective clients and partners understand this service catalogue, discuss initial requirements and prepare questions for a human representative.

## Business categories

- Software development
- IT services
- Business automation

## Sample service catalogue

### Web application development

Business websites, internal dashboards, customer portals and administrative applications. A typical requirements discussion covers user roles, business workflows, integrations and reporting needs.

### Mobile application development

Mobile application planning, prototypes and business applications. Requirements depend on the target users, supported devices, required features and existing backend systems.

### Business process automation

Software workflows for repetitive tasks such as collecting requests, tracking approvals, updating records and preparing reports. Discovery starts with the current process and the desired outcome.

### Software integrations

API development and integrations between business systems. A discussion should identify the systems involved, available API documentation, data formats, access requirements and expected events.

### Application maintenance

Reviewing existing applications, investigating bugs and assessing requested improvements. Support scope and availability require confirmation by a human representative.

## Information needed for a project discussion

A prospective client can provide the following non-confidential information:

1. A short description of the business problem.
2. The intended users and approximate usage.
3. The main features or workflows required.
4. Existing applications that need integration.
5. Public API documentation, where available.
6. Preferred technologies, if any.
7. An indicative budget range and preferred timeline.
8. The next step they would like to discuss with a human representative.

Passwords, access tokens, production credentials, customer records and confidential contracts are not needed for an initial conversation.
