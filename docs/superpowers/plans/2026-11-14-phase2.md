## Design

Company owns users/memberships, agent configurations, knowledge and policies. Conversations have no owner company: access requires an active membership belonging to the requesting user's selected company. Membership records store a history start sequence; new joins see subsequent messages only. Removed members grant no access. Each member pins a configuration version. Agent lifecycle and latest company policy are rechecked at execution and persistence. Private knowledge is never sent to a cross-company model context; only sources explicitly designated shareable can be retrieved there. The replaceable retrieval interface always requires company and agent scope.

Messages and deliveries are committed together (deliveries serve as the transactional outbox). A worker atomically claims a lease, uses a global database runtime mutex only for short reservation/finalization transactions, and releases the database before provider I/O. The reservation checks company/platform/agent limits; finalization rechecks emergency controls and leases. Sent turns count persisted replies only. Lease recovery ends abandoned attempts before retry. No synchronous recursive replies.
